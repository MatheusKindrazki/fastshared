# FastShared — taglines and pitches

One-liners and elevator pitches. The final tagline is the hero of the landing
page, the App Store subtitle hook, and the anchor line on every launch
surface.

---

## Tagline — 5 options, ranked

**1. Final (recommended).**

```
Share anything. Get a link. Watch it vanish.
```

(45 / 60) — already in use as the hero headline on the landing page. Four
short beats, each a complete thought, ending on the differentiator. No jargon,
no feature names, no adjectives. This is the one.

**2. Runner-up.**

```
Temporary share links for iPhone, iPad and Mac.
```

(47 / 60) — literal, keyword-heavy, plays well in the App Store subtitle and
on paid search. Weaker as a brand tagline because it describes category, not
posture. Use for ad copy, not for the hero.

**3. Alternate posture.**

```
One gesture. One link. One countdown.
```

(37 / 60) — the most poetic of the set; carries the concept without naming
the product. Weaker for discovery because it contains zero ASO words.

**4. For privacy-driven channels (HN, BlueSky, r/privacy).**

```
Share a file without leaving a trail.
```

(37 / 60) — reframes the product around the privacy benefit. Good for a
thread header or a paid-ad rotation — not for the primary brand tagline.

**5. Utility-shelf variant.**

```
Fast. Shared. Gone.
```

(19 / 60) — almost haiku, but too abstract to stand on its own. Keep for
merch, sticker, the back of a laptop, the end of a Keynote slide — not the
home page.

## Elevator pitches

### 25 words

FastShared is a native Apple utility that turns any file into a temporary
shareable link, already on your clipboard, that deletes itself on schedule.

(25 words)

### 50 words

FastShared is a native Apple utility that turns "share a file" into "get a
temporary link on my clipboard" in a single gesture. Every link is temporary
by design — default 24 hours, custom up to 30 days — and the underlying file
is deleted automatically when the window closes.

(50 words)

### 100 words

FastShared is a native iOS, iPadOS, and macOS utility that collapses the
everyday "share a file" chore into one gesture. Pick any file from any app,
pick how long the link should live, and the short URL is already on your
clipboard before the upload finishes. Every link expires on schedule;
afterwards the underlying file is hard-deleted. No accounts, no folders, no
recipients to manage — the link is the credential, and when it's gone it's
gone. Built on Cloudflare Workers and R2, with a Live Activity on iPhone 14
Pro and universal clipboard hand-off to Mac.

(99 words)

## Mission — "why it exists" (80 words)

The share sheet is the fastest interface on any Apple device. Dropbox is not.
Drive is not. A file sent over messaging is hostage to the messaging app
forever. FastShared exists because sending a file should cost one gesture and
should not leave permanent residue on the internet. Every link is a promise
to disappear on a schedule you pick. No accounts, no libraries, no graveyard
of forgotten uploads — just a link that does its job, then stops existing.

(79 words)
